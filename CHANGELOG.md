# Change Log

- 2026-08-30 **3.0.0.0**
  - Added Revit 2027 (R27) support, targeting .NET 10 (`net10.0-windows`)
  - Added AutoCAD 2027 support
  - Output packages for R27 deploy to Dynamo 4.0, the version shipped with Revit 2027

- 2026-03-25 **3.0.0.0**
  - Added Revit 2026 (R26) support
  - Added AutoCAD 2026 support
  - Added Civil 3D 2026 support
  - Updated to .NET 8.0 for R25 and R26 configurations
  - Updated Dynamo version to 3.0+ for R25/R26
  - Fixed NuGet package resolution for multi-version builds
  - Fixed Marshal.GetActiveObject compatibility for .NET 8
  - Added default configuration properties to prevent build errors
  - Improved build system stability

- 2022-11-13 **1.0.0.0**
  - Initial release
